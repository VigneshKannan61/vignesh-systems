# Vignesh Kannan — AI Receptionist & Lead Automation for US MedSpas

Official repository for the personal brand website of **Vignesh Kannan**, independent AI automation specialist.

---

## Project Purpose
A custom-built, lightweight, single-page business landing page focused strictly on solving one central problem for independent US medical spas: **handling missed inbound calls and responding immediately to prospective patient inquiries.**

---

## Architectural Stack
- **Structure:** Semantic HTML5
- **Design & Layout:** Vanilla CSS3 (Custom properties, Flexbox, Grid)
- **Interactivity:** Vanilla JavaScript (ES6+)
- **Typography:** Google Fonts (`Manrope` + `Inter`)
- **Hosting Target:** Cloudflare Pages (Static Edge Distribution)
